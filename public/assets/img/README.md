# Logo file goes here

Drop your barangay logo as `logo.png` in this folder (or `.jpg` / `.svg` —
just update the `src` path in `public/assets/js/components.js` → `sealSvg()`
to match your filename).

Recommended: a square image, at least 200x200px, transparent or white
background works best since it renders inside a circle.

If this file is missing, the site automatically falls back to the
generated navy/gold seal — nothing breaks either way.
